`Material-Design-Iconic-Font.ttf` is the [Material Design Iconic Font](https://github.com/zavoloklom/material-design-iconic-font) by Sergey Kupletsky. Its font files are licensed under the SIL Open Font License 1.1 ([source](https://zavoloklom.dev/material-design-iconic-font/license.html)); the license text is in [OFL.txt](OFL.txt). The font is not covered by this repository's WTFPL license.

The patched ModernZ uses it for the play/pause icon. It is shipped unmodified, together with `OFL.txt`; `tools/install.py` and the release zip copy both into `fonts/`.
