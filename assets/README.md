# assets

`Material-Design-Iconic-Font.ttf` is the [Material Design Iconic Font](https://github.com/zavoloklom/material-design-iconic-font) by Sergey Kupletsky (the font is licensed under the SIL Open Font License 1.1). The patched ModernZ uses it for the play/pause icon. It is shipped unmodified; `tools/install.py` and the release zip copy it into `fonts/`.
